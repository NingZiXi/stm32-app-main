# 应用代码注释

仅用于本技能移植到消费工程的业务代码。先遵守目标工程的 AGENTS.md、既有源码与用户要求；这里的模板偏好不作为组件库的公共接口规范。

- 文件头用简短 `@file`、`@brief`；模板已有的作者、版本和日期元数据按实际工程处理，不能照抄个人身份或旧日期。
- 函数说明写用途、参数语义和必要副作用；不要机械复述签名。目标工程要求 Doxygen 时遵守其公共接口契约，不因模板偏好删掉必要标记。
- 宏、变量和结构体字段可用简短同行尾注释；实现内说明关键约束和原因，避免章节分隔线与大段教学注释。版式以目标工程为准。
- 第三方代码保留其要求的版权和许可证，不为统一注释而移除。

示例见 [UART FreeRTOS 模板](../assets/app_main.c) 和 [UART 裸机模板](../assets/app_main_bare.c)；只读当前任务选择的模板。
